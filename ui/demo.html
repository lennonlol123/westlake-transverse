Westlake TransVerse

Explore five Universes. Discover how your actions change what happens, keep your own notes, and carry your experience into the next place.

Each Universe contains four Episodes. An Episode ends if you lose an Encounter. Your notes carry forward; your current Encounter's working note does not.

Public play version. No account or API key is needed. Your actions and notes stay in this browser and are not submitted to the researchers. Export a save if you want to share it. This is separate from the original study.

The first start downloads a browser Python runtime. A desktop or laptop browser is recommended. Source code and instructions
